没有噪音的告警

安装后即启用有用的规则。工作重心在于发送更少、更有价值的消息。

  • 依赖关系

    把交换机声明为其下游监控项的父级。它宕机时你只收到一条通知，而不是三十条；其余显示为“被上级抑制”。

  • 按主机分组

    阵列降级的 NAS 每个周期只发一条消息，而不是每块磁盘一条。提醒、升级、确认、暂停提醒、按监控项忽略和清除已解决的历史，全部内置。

  • 先学习的基线

    无需调阈值的异常检测：168 个时段，对应一周中的每个小时。前 14 天保持静默，只显示它本来会触发什么。

  • 预报

    “该文件系统将在四天内写满”会作为预报列出，与当前已经出问题的内容分开。

  • 维护与通知策略

    一次性或每周的窗口、滞后、抖动保持、安静时段、批量发送和每小时上限，让糟糕的一夜不会变成两百条推送。

为不支持 SNMP 的监控项准备的代理

一个小型二进制程序，把 CPU、内存、磁盘、网络、服务和运行时间推送到服务器，机器提供时还包括温度、风扇、SMART 和 ZFS 存储池。由它主动连接服务器，而不是反过来：机器上无需开放任何端口。

# 界面会自动为你填入令牌
curl -sSL http://server:8080/install.sh | sh -s -- \
  --token=dmon_xxx --url=http://server:8080

Windows 上可从 /install.ps1 获取 PowerShell 脚本。代理也提供镜像：ghcr.io/laupernoe/dumbmonit-agent。

  • Linux已支持x86_64 和 aarch64，systemd 或 OpenRC。Docker 容器和操作系统健康状况（更新、待重启、失败的单元）。
  • Windows已支持x86_64，作为 Windows 服务安装。通过 smartctl 获取 SMART。
  • macOS预览版launchd，Apple silicon 和 Intel；二进制文件随每个版本发布。尚未在真实硬件上运行。
  • FreeBSD预览版rc.d，x86_64，ZFS 存储池。尚未在真实硬件上运行。
  • 远程站点，仅出站连接

    在中继模式下，代理从自己所在的网络——第二个站点、客户的网络或 NAT 后的 VPS——运行服务器的探测（SNMP、Proxmox、HTTP…），无需任何入站连接：不用 VPN，也不用开放端口。监控远程站点

面向你的服务对象的状态页

公开页面位于 /s/<name>：服务分组，含 90 天的每日历史、30 天和 90 天可用率、事件与维护公告、采用双重确认的电子邮件订阅者、RSS、可用于 README 的徽章、适合内网的精简嵌入，以及可选的 90 天日历和响应时间图表，还有横幅后可选的场景：约五十种可选，从城市天际线（威尼斯、巴黎、东京、纽约…）和世界奇观，到瑞士地标（马特洪峰、日内瓦大喷泉、卢塞恩、伯尔尼、西庸城堡）。天空随服务状态变化，每个场景在服务宕机或恢复时都有各自的反应。瑞士场景配有 SBB 风格的车站时钟、翻页式告警牌、8 月 1 日的烟花、日内瓦的“Escalade”汤锅庆典和冬季雪景。

只有你选择的标签会离开服务器。监控项名称、地址和类型绝不会出现在页面、徽章或邮件中。

文档中的状态页

  • 在手机上

    查看状态、确认告警、开启维护窗口。可安装到主屏幕，刻意不提供离线模式：它绝不会显示昨天的状态。

墙面模式

只显示概览，全屏，适合房间里的显示器：一幅动态场景（默认是有埃菲尔铁塔和 DumbMonit 鸽子的巴黎屋顶，也可选其他许多场景），其天气随告警变化；为长时间开着的屏幕准备的 OLED 主题；以及墙面音乐 — Spotify Connect 能把屏幕变成音箱。

邮件报告

每周（或每天、每月）一封简短邮件，包含各分组的可用性、该时段的事件以及最不稳定的监控项，无需任何人打开 DumbMonit。

安全评分

每个受支持的监控项都会根据厂商自身的最佳实践检查，获得 0–100 的分数和 A–F 的等级，类似 PingCastle：类别、严重程度、证据、修复建议，以及按最差优先排序的“安全”页面。

该评分仅供参考，不是审计：它只读取 DumbMonit 已经采集的数据，因此不能替代安全审查。

API 与助手

  • 开放且有文档的 API

    所有路由都列在 /api/openapi.json（OpenAPI 3.1）中：带作用域的令牌（dmt_…，只读或可写），可设置过期、限制网络来源，并有速率限制。API 参考

  • 通过 MCP 使用的助手

    面向 ChatGPT、VS Code 或 Cursor 的 27 个工具：读取状态、监控项、告警、指标和代理；具有写权限的令牌还可以静音、确认告警、添加监控项或重启容器。密钥绝不会返回。连接助手
