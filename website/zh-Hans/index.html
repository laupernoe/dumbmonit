Alpha 版，面向早期测试者 Apache 2.0，没有付费版

一切正常吗？一秒钟就知道。

极简的自托管监控，从家庭实验室到小型企业。一个容器，输入一个 IP 地址，不到一分钟就能看到有用的图表和告警。

$ mkdir dumbmonit && cd dumbmonit
$ curl -fsSLO https://raw.githubusercontent.com/laupernoe/dumbmonit/main/docker-compose.yml
$ docker compose up -d

然后打开 http://localhost:8080 并创建第一个账户。镜像支持 amd64（arm64 稍后提供）：ghcr.io/laupernoe/dumbmonit。

试用在线演示 在 GitHub 上查看 阅读安装指南

这是 Alpha 版本（当前发布版为 0.1.0-alpha.7）。DumbMonit 每天都在作者自己的网络中运行，但 HTTP API 尚未冻结，数据库结构仍在变动，目前也不保证跨结构变更的升级。部分集成只在测试实例上验证过，没有经过多年的生产硬件考验，下文已作标注。欢迎试用，并告诉我们哪里出了问题。

  • 一个容器，一分钟

    单个容器、一个卷，无需额外权限。打开页面，创建账户，添加设备：图表和告警随之而来。

  • 安静的告警

    实用规则从一开始就已启用。依赖关系、分组和学习得到的基线，把三十条消息变成一条。

  • 65 种设备类型

    交换机、防火墙、虚拟化平台、NAS、网站、数据库和自托管应用，各自按厂商期望的方式读取。

  • 状态页与墙面大屏

    向用户分享公开状态页，或把“天气预报”视图放在房间的屏幕上。
