安装 DumbMonit

一个容器，三个步骤。之后再在服务器上添加代理。

  1. 下载 Compose 文件

    新建一个文件夹并获取该文件。它已去除所有 capability，并以只读方式挂载文件系统。

    $ mkdir dumbmonit && cd dumbmonit
$ curl -fsSLO https://raw.githubusercontent.com/laupernoe/dumbmonit/main/docker-compose.yml

  2. 启动

    Docker 拉取镜像，并连同时序数据库一起启动 DumbMonit。

    $ docker compose up -d

  3. 创建第一个账户

    打开页面并创建管理员。然后添加设备：表单会说明需要在设备上准备什么。

    然后打开 http://localhost:8080 并创建第一个账户。镜像支持 amd64（arm64 稍后提供）：ghcr.io/laupernoe/dumbmonit。

您需要准备

  • 带 Compose 插件的 Docker Engine。
  • 一台 amd64 机器；arm64 镜像暂时搁置。
  • 空闲的 8080 端口，或您选择的其他端口。
  • 能访问被监控的设备的网络。除代理外，设备无需访问服务器。

然后在服务器上添加代理

一个小型二进制程序，把 CPU、内存、磁盘、网络、服务和运行时间推送到服务器，机器提供时还包括温度、风扇、SMART 和 ZFS 存储池。由它主动连接服务器，而不是反过来：机器上无需开放任何端口。

# 界面会自动为你填入令牌
curl -sSL http://server:8080/install.sh | sh -s -- \
  --token=dmon_xxx --url=http://server:8080

Windows 上可从 /install.ps1 获取 PowerShell 脚本。代理也提供镜像：ghcr.io/laupernoe/dumbmonit-agent。

代理文档

  • Linux已支持x86_64 和 aarch64，systemd 或 OpenRC。Docker 容器和操作系统健康状况（更新、待重启、失败的单元）。
  • Windows已支持x86_64，作为 Windows 服务安装。通过 smartctl 获取 SMART。
  • macOS预览版launchd，Apple silicon 和 Intel；二进制文件随每个版本发布。尚未在真实硬件上运行。
  • FreeBSD预览版rc.d，x86_64，ZFS 存储池。尚未在真实硬件上运行。

DumbMonit，Apache 2.0。吉祥物是一只鸽子。
