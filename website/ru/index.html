Живое демо GitHub
Альфа-версия, для первых тестировщиков Apache 2.0, платной редакции нет

Всё в порядке? Узнайте за одну секунду.

Предельно простой self-hosted мониторинг — от домашней лаборатории до небольшой компании. Один контейнер, один IP-адрес для ввода, полезные графики и оповещения меньше чем за минуту.

$ mkdir dumbmonit && cd dumbmonit
$ curl -fsSLO https://raw.githubusercontent.com/laupernoe/dumbmonit/main/docker-compose.yml
$ docker compose up -d

Затем откройте http://localhost:8080 и создайте первую учётную запись. Образ для amd64 (arm64 позже): ghcr.io/laupernoe/dumbmonit.

Это альфа-версия (текущий релиз — 0.1.0-alpha.8). DumbMonit каждый день работает в сети своего автора, но HTTP API ещё не зафиксирован, схема базы данных продолжает меняться, а гарантий обновления между изменениями схемы пока нет. Часть интеграций проверялась только на тестовых экземплярах, а не на многолетнем боевом оборудовании; они отмечены ниже. Попробуйте и расскажите, что сломалось.

  • Один контейнер, одна минута

    Один контейнер с одним томом и без лишних capabilities. Откройте страницу, создайте учётную запись, добавьте монитор: графики и оповещения появятся сами.

  • Оповещения без лишнего шума

    Полезные правила включены с самого начала. Зависимости, группировка и выученные базовые уровни превращают тридцать сообщений в одно.

  • 65 типов мониторов

    Коммутаторы, межсетевые экраны, гипервизоры, NAS, сайты, базы данных и приложения для самостоятельного хостинга: каждое читается так, как задумал производитель.

  • Страницы статуса и настенный экран

    Поделитесь публичной страницей статуса с пользователями или выведите «сводку погоды» на экран в комнате.

    Proxmox, vSphere, XCP-ng, Nutanix и Kubernetes: хосты, гостевые системы, хранилище и состояние кластера.

    Веб-страницы и API, порты, DNS, ping, TLS-сертификаты, серверы времени, срок действия доменов, heartbeat и изменения сайтов.
