Установка DumbMonit

Один контейнер, три шага. Затем добавьте агент на серверы.

  1. Скачайте файл Compose

    Создайте папку и скачайте файл. В нём уже отброшены все capabilities, а файловая система смонтирована только для чтения.

    $ mkdir dumbmonit && cd dumbmonit
$ curl -fsSLO https://raw.githubusercontent.com/laupernoe/dumbmonit/main/docker-compose.yml

  2. Запустите

    Docker скачает образ и запустит DumbMonit вместе с базой временных рядов.

    $ docker compose up -d

  3. Создайте первую учётную запись

    Откройте страницу и создайте администратора. Затем добавьте монитор: форма подскажет, что на нём подготовить.

    Затем откройте http://localhost:8080 и создайте первую учётную запись. Образ для amd64 (arm64 позже): ghcr.io/laupernoe/dumbmonit.

Что понадобится

  • Docker Engine с плагином Compose.
  • Машина amd64; образы arm64 пока приостановлены.
  • Свободный порт 8080 или любой другой по вашему выбору.
  • Сетевой доступ к отслеживаемым мониторам. Им не нужно связываться с сервером, кроме агентов.

Затем добавьте агент на серверы

Небольшой бинарный файл, который отправляет на сервер данные о CPU, памяти, дисках, сети, службах и времени работы, а также о температурах, вентиляторах, SMART и пулах ZFS, если машина их предоставляет. Он сам обращается к серверу, а не наоборот: на машине не нужно открывать порты.

# интерфейс подставит токен за вас
curl -sSL http://server:8080/install.sh | sh -s -- \
  --token=dmon_xxx --url=http://server:8080

Для Windows по адресу /install.ps1 отдаётся скрипт PowerShell. Агент также доступен как образ ghcr.io/laupernoe/dumbmonit-agent.

Документация агента

  • LinuxПоддерживаетсяx86_64 и aarch64, systemd или OpenRC. Контейнеры Docker и состояние ОС (обновления, ожидающая перезагрузка, упавшие юниты).
  • WindowsПоддерживаетсяx86_64, устанавливается как служба Windows. SMART через smartctl.
  • macOSПредварительная версияlaunchd, Apple silicon и Intel; бинарные файлы прикладываются к каждому релизу. Пока не запускалось на реальном оборудовании.
  • FreeBSDПредварительная версияrc.d, x86_64, пулы ZFS. Пока не запускалось на реальном оборудовании.
