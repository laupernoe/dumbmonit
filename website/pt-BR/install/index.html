Instalar o DumbMonit

Um contêiner, três etapas. Depois, adicione o agente aos seus servidores.

  1. Baixar o arquivo Compose

    Crie uma pasta e baixe o arquivo. Ele já remove todas as capabilities e monta o sistema de arquivos só de leitura.

    $ mkdir dumbmonit && cd dumbmonit
$ curl -fsSLO https://raw.githubusercontent.com/laupernoe/dumbmonit/main/docker-compose.yml

  2. Iniciar

    O Docker baixa a imagem e inicia o DumbMonit com a sua base de dados de séries temporais.

    $ docker compose up -d

  3. Criar a primeira conta

    Abra a página e crie o administrador. Depois adicione um dispositivo: o formulário indica o que preparar nele.

    Depois abra http://localhost:8080 e crie a primeira conta. Imagem para amd64 (arm64 em breve): ghcr.io/laupernoe/dumbmonit.

O que você precisa

  • Docker Engine com o plugin Compose.
  • Uma máquina amd64; as imagens arm64 estão em pausa por enquanto.
  • A porta 8080 livre, ou outra porta à sua escolha.
  • Acesso de rede aos dispositivos monitorados. Não precisam de alcançar o servidor, exceto os agentes.

Depois, adicione o agente aos seus servidores

Um pequeno binário que envia ao servidor CPU, memória, discos, rede, serviços e tempo de atividade, além de temperaturas, ventoinhas, SMART e pools ZFS quando a máquina os expõe. Ele chama o servidor, nunca o contrário: nenhuma porta para abrir na máquina.

# a interface preenche o token para você
curl -sSL http://server:8080/install.sh | sh -s -- \
  --token=dmon_xxx --url=http://server:8080

Para Windows, um script PowerShell é servido em /install.ps1. O agente também existe como imagem, ghcr.io/laupernoe/dumbmonit-agent.

Documentação do agente

  • LinuxSuportadox86_64 e aarch64, systemd ou OpenRC. Contêineres Docker e saúde do SO (atualizações, reinicialização pendente, units com falha).
  • WindowsSuportadox86_64, instalado como serviço do Windows. SMART via smartctl.
  • macOSPrévialaunchd, Apple silicon e Intel; binários anexados a cada release. Ainda não testado em hardware real.
  • FreeBSDPréviarc.d, x86_64, pools ZFS. Ainda não testado em hardware real.

DumbMonit, Apache 2.0. O mascote é um pombo.
