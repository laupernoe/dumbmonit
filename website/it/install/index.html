Installa DumbMonit

Un container, tre passaggi. Poi aggiungi l'agent ai tuoi server.

  1. Scarica il file Compose

    Crea una cartella e scarica il file. Rimuove già tutte le capability e monta il file system in sola lettura.

    $ mkdir dumbmonit && cd dumbmonit
$ curl -fsSLO https://raw.githubusercontent.com/laupernoe/dumbmonit/main/docker-compose.yml

  2. Avvialo

    Docker scarica l'immagine e avvia DumbMonit insieme al suo database di serie temporali.

    $ docker compose up -d

  3. Crea il primo account

    Apri la pagina e crea l'amministratore. Poi aggiungi un monitor: il modulo dice cosa preparare su di esso.

    Poi apri http://localhost:8080 e crea il primo account. Immagine per amd64 (arm64 in seguito): ghcr.io/laupernoe/dumbmonit.

Cosa serve

  • Docker Engine con il plugin Compose.
  • Una macchina amd64; le immagini arm64 sono in pausa per ora.
  • La porta 8080 libera, o un'altra porta a scelta.
  • Accesso di rete ai monitor monitorati. Non devono raggiungere il server, tranne gli agent.

Per approfondire

  • Guida all'installazione completa
  • Aggiungi il tuo primo monitor
  • Aggiornare
  • Backup e ripristino
  • Sedi remote

Poi aggiungi l'agent ai tuoi server

Un piccolo binario che invia al server CPU, memoria, dischi, rete, servizi e uptime, più temperature, ventole, SMART e pool ZFS dove la macchina li espone. È lui a chiamare il server, mai il contrario: nessuna porta da aprire sulla macchina.

# l'interfaccia compila il token per te
curl -sSL http://server:8080/install.sh | sh -s -- \
  --token=dmon_xxx --url=http://server:8080

Per Windows è servito uno script PowerShell su /install.ps1. L'agent è disponibile anche come immagine, ghcr.io/laupernoe/dumbmonit-agent.

Documentazione dell'agent

  • LinuxSupportatox86_64 e aarch64, systemd o OpenRC. Container Docker e salute del sistema operativo (aggiornamenti, riavvio in sospeso, unit fallite).
  • WindowsSupportatox86_64, installato come servizio Windows. SMART tramite smartctl.
  • macOSAnteprimalaunchd, Apple silicon e Intel; binari allegati a ogni release. Non ancora provato su hardware reale.
  • FreeBSDAnteprimarc.d, x86_64, pool ZFS. Non ancora provato su hardware reale.

DumbMonit, Apache 2.0. La mascotte è un piccione.
