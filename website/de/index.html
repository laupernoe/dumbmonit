Ist alles in Ordnung? Antwort in einer Sekunde.

Selbst gehostetes Monitoring, so einfach wie möglich – vom Homelab bis zum Kleinunternehmen. Ein Container, eine IP-Adresse zum Eintippen, nützliche Diagramme und Alarme in unter einer Minute.

$ mkdir dumbmonit && cd dumbmonit
$ curl -fsSLO https://raw.githubusercontent.com/laupernoe/dumbmonit/main/docker-compose.yml
$ docker compose up -d

Öffnen Sie danach http://localhost:8080 und legen Sie das erste Konto an. Image für amd64 (arm64 folgt): ghcr.io/laupernoe/dumbmonit.

Live-Demo ausprobieren Auf GitHub ansehen Installationsanleitung lesen

DumbMonit ist noch vor 1.0 (aktuell ist 0.9.0). Es läuft täglich im eigenen Netz seines Autors, aber die HTTP-API und das Datenbankschema können sich zwischen Minor-Versionen noch ändern; das Änderungsprotokoll erklärt das Update. Mehrere Integrationen kennen bisher nur Testinstanzen, keine jahrealte Produktionshardware; sie sind unten gekennzeichnet. Probieren Sie es aus und sagen Sie uns, was kaputtgeht.

  • Ein Container, eine Minute

    Ein einziger Container mit einem Volume und ohne zusätzliche Capabilities. Seite öffnen, Konto anlegen, Gerät hinzufügen: Diagramme und Alarme folgen.

  • Alarme, die leise bleiben

    Nützliche Regeln sind von Anfang an aktiv. Abhängigkeiten, Gruppierung und gelernte Basiswerte machen aus dreißig Nachrichten eine.

  • 65 Gerätetypen

    Switches, Firewalls, Hypervisoren, NAS, Websites, Datenbanken und selbst gehostete Apps, jedes so gelesen, wie der Hersteller es vorsieht.

  • Statusseiten und Wandanzeige

    Teilen Sie eine öffentliche Statusseite mit Ihren Nutzern oder zeigen Sie die Wetterbericht-Ansicht auf einem Bildschirm im Raum.
