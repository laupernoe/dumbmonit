Open source, all of it

Apache 2.0, dependencies included: CI fails on any dependency that is not under an OSI-approved licence. No feature is held back for a paid edition, because there is none.

Tell us what breaks

A monitor that reads wrong, an alert that woke you for nothing, a page that confused you: each report makes the next release better. Requests for a new kind of monitor are welcome too.
