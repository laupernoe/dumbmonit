Installer DumbMonit

Un conteneur, trois étapes. Ajoutez ensuite l'agent à vos serveurs.

  1. Télécharger le fichier Compose

    Créez un dossier et récupérez le fichier. Il retire déjà toutes les capabilities et monte le système de fichiers en lecture seule.

    $ mkdir dumbmonit && cd dumbmonit
$ curl -fsSLO https://raw.githubusercontent.com/laupernoe/dumbmonit/main/docker-compose.yml

  2. Le démarrer

    Docker télécharge l'image et lance DumbMonit avec sa base de séries temporelles.

    $ docker compose up -d

  3. Créer le premier compte

    Ouvrez la page et créez l'administrateur. Ajoutez ensuite une surveillance : le formulaire dit ce qu'il faut préparer sur l'appareil.

    Ouvrez ensuite http://localhost:8080 et créez le premier compte. Image pour amd64 (arm64 plus tard) : ghcr.io/laupernoe/dumbmonit.

Ce qu'il faut

  • Docker Engine avec le plugin Compose.
  • Une machine amd64 ; les images arm64 sont en pause pour l'instant.
  • Le port 8080 libre, ou un autre port de votre choix.
  • Un accès réseau aux appareils supervisés. Ils n'ont pas besoin de joindre le serveur, sauf les agents.

Puis ajoutez l'agent à vos serveurs

Un petit binaire qui envoie au serveur le CPU, la mémoire, les disques, le réseau, les services et la disponibilité, ainsi que les températures, ventilateurs, SMART et pools ZFS quand la machine les expose. C’est lui qui appelle le serveur, jamais l’inverse : aucun port à ouvrir sur la machine.

# l’interface renseigne le jeton pour vous
curl -sSL http://server:8080/install.sh | sh -s -- \
  --token=dmon_xxx --url=http://server:8080

Un script PowerShell est servi sur /install.ps1 pour Windows. L’agent existe aussi sous forme d’image, ghcr.io/laupernoe/dumbmonit-agent.

Documentation de l'agent

  • LinuxPris en chargex86_64 et aarch64, systemd ou OpenRC. Conteneurs Docker et santé du système (mises à jour, redémarrage en attente, unités en échec).
  • WindowsPris en chargex86_64, installé comme service Windows. SMART via smartctl.
  • macOSPréversionlaunchd, Apple silicon et Intel ; binaires joints à chaque version. Pas encore testé sur du vrai matériel.
  • FreeBSDPréversionrc.d, x86_64, pools ZFS. Pas encore testé sur du vrai matériel.

DumbMonit, Apache 2.0. La mascotte est un pigeon.
