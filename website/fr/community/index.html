Open source, entièrement

Apache 2.0, dépendances comprises : la CI échoue pour toute dépendance qui n’est pas sous licence approuvée par l’OSI. Aucune fonctionnalité n’est réservée à une édition payante, car il n’y en a pas.

Dites-nous ce qui casse

Une surveillance mal lue, une alerte qui vous a réveillé pour rien, une page qui vous a embrouillé : chaque retour améliore la prochaine alpha. Les demandes de prise en charge d’un nouveau type de surveillance sont aussi les bienvenues.
