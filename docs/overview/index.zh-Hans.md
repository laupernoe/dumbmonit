# 概览

左侧菜单的第一项(`g o`):一切是否正常,以及哪些需要您处理。夜空横幅用一句话说明,接着是五个指标和健康河流,然后是每个监控项,最差的排在前面。受团队或客户限制的账户没有概览,从**监控项**开始。

同样的看板全屏显示就是**墙屏模式**:位于左侧菜单底部的屏幕图标,带有自己的音乐。

| 在应用中的位置 | 显示内容 | 阅读 |
|---|---|---|
| **概览** | 横幅、五个指标、健康河流、监控项表格和上下文面板 | [概览页面](../using/overview.md) |
| **墙屏模式**(左侧菜单底部) | 给房间里的屏幕用的黑色看板:结论、时钟、未处理的告警、谁在值班,以及音乐 | [墙屏模式与音乐](../using/wall.md) |
| **设置 › 墙屏显示** | 墙屏显示的内容,以及在其上播放的**墙屏音乐** | [墙屏模式与音乐](../using/wall.md#music-on-the-wall) |
