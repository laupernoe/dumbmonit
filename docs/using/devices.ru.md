# Страница устройств

![Стойка: одна лицевая панель на устройство](../assets/screenshots/devices-light.png){ loading=lazy }

## Стойка

Каждое устройство — это лицевая панель на 1U: светодиод состояния, имя, метка
типа, адрес, когда оно было замечено последний раз, и спарклайн представляющей
метрики. Дочерние устройства группируются под своим родителем и тускнеют, когда
родитель недоступен.

| Состояние | Значение |
|---|---|
| Reporting | Последняя проверка прошла успешно, в пределах трёх периодов. |
| Unreachable | Устройство не ответило (таймаут, соединение отклонено), либо проверок не было более трёх периодов (не менее 90 с). |
| Misconfigured | Последняя проверка завершилась ошибкой на нашей стороне: неверные учётные данные, недопустимый адрес или опция, неожиданный ответ. Показывается цветом advisory с ошибкой; не вызывает оповещения. |
| Waiting | Добавлено, ещё не проверялось. |
| Disabled | На паузе: не проверяется, не вызывает оповещения. |

Фильтры: поле поиска, переключатель состояния (All, Needs attention, Reporting,
Disabled) и фильтр по типу. **Add a device** — основное действие.

Кнопка **Select** (операторам и администраторам) включает флажок у каждого
устройства и плавающую панель внизу с массовыми действиями; **Done** или
Escape выходит из режима.

## Устройство

![Страница устройства: состояние, действия, оповещения, панель, специфичная для типа, метрики](../assets/screenshots/device-light.png){ loading=lazy }

Страница устройства показывает его плашку состояния, адрес, тип, обнаруженный
профиль, теги, последнюю проверку и, для сервисов, состояние сертификата.
Действия:

| Действие | Эффект |
|---|---|
| Probe now | Немедленно выполняет одну проверку и сообщает, сколько образцов и рядов она произвела. Первое, что стоит попробовать, когда устройство не показывает данных. |
| Edit | Открывает ту же форму, что при добавлении, предзаполненную. Если оставить учётные данные пустыми, сохранённые остаются. |
| Silence 1 h / Silence until… | Разовое окно обслуживания для этого устройства. |
| Delete | Пять секунд показывает прямо на месте «Delete for good?», затем удаляет устройство. Его ряды остаются в VictoriaMetrics до истечения срока хранения. |

Ниже: **Alerts on this device** — каждое активное оповещение предлагает *Ack*,
*Snooze* и *Ignore*, а правило, игнорируемое на этом устройстве, перечислено
отдельно с кнопкой **Stop ignoring** — затем **Metrics** за выбранный период
(1 ч, 6 ч, 24 ч, 7 дней), один график на имя метрики с одной линией на ряд. См.
[Как убрать оповещение](alerts.md#getting-rid-of-an-alert).

Сервисы (HTTP, TCP, DNS, ping, TLS) получают вместо этого свои приборы:
**Availability** за последние 24 часа или 7 дней, **Response time**, число
**Checks**, и столбец **History** из слотов (самый старый слева), показывающий,
когда сервис был недоступен.

## Политики контейнеров

На машине с агентом и Docker под заголовком находится полоса **Docker**: число
контейнеров, сколько работают, доступные обновления и сколько контейнеров
имеют политику. **Manage containers** открывает список; **Policies…** открывает
таблицу с двумя переключателями на контейнер и строкой «Apply to all»:

- **Restart if down** — сервер перезапускает контейнер в течение минуты после
  его остановки (не чаще раза в десять минут);
- **Auto-update in maintenance windows** — когда в реестре появляется более
  новый образ для того же тега, контейнер пересоздаётся во время запланированного
  окна обслуживания (страница Alerts → Maintenance) и откатывается, если не
  проходит проверку здоровья.

Каждый переключатель сохраняется самостоятельно. Подробности и правила
безопасности: [Контейнеры Docker](../devices/agent.md#docker-containers).

## Добавление и редактирование

См. [Добавьте первое устройство](../install/first-device.md) для формы и
[типы устройств](../devices/index.md) для того, что нужно каждому типу. При
редактировании форма сама открывает **More options**, если устройство уже
использует одну из них.

## Удаление

Удаление устройства убирает его из конфигурации, сразу же сбрасывает его
оповещения — ничего не уведомляется, история сохраняет строку
`device removed or disabled` — и удаляет его временные ряды из встроенной
VictoriaMetrics через несколько секунд (с максимальными усилиями: сбой только
журналируется, и тогда ряды сами устаревают при истечении 12-месячного срока
хранения). Приостановка устройства сбрасывает его оповещения так же; его ряды
остаются.
