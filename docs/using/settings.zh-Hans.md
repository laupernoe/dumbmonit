# 设置 {#settings}

![Settings: account, users, single sign-on, agents, assistant, appearance, about](../assets/screenshots/settings-light.png){ loading=lazy }

设置页面存放与管理相关的内容：你的账户、谁可以登录以及如何登录、让代理和助手接入的令牌、实例备份、主题，以及服务器的健康状况。一个页面，每个主题一个分区，宽屏上有锚点导航栏，手机上则是一排标签条。每个分区都可以直接链接（`/settings#agents`）。

曾经有两项内容放在这里，后来移出了，因为它们不属于管理范畴：

| 要找的内容 | 现在位于 | 旧链接 |
|---|---|---|
| 通知渠道、静默时段、通知策略 | **告警 → 通知**（[告警页面](alerts.md#notifications)） | `/settings#notifications`、`/settings#notifications-policy` |
| 状态页面与公告 | **状态**（[状态页面](status-pages.md)） | `/settings#status` |

旧链接仍然有效：它们会跳转到新位置。

## 账户与安全 {#account--security}

这是你自己的账户。第一个账户在首次启动时创建，更多账户可在下方添加。在这里修改密码：当前密码、新密码（至少 12 个字符；一整句短语比复杂的单词更安全）、确认。修改密码会使所有其他会话登出。通过身份提供方登录的账户在这里没有密码。**登出**会结束当前会话。

登录按客户端地址和账户进行速率限制：失败五次后，每次后续尝试等待的时间更长（30 秒，逐次翻倍，最长 5 分钟）。在反向代理之后，请设置 `DUMBMONIT_TRUSTED_PROXIES`，让限流器看到真实的客户端地址而不是代理的地址（参见[配置](../reference/configuration.md)）。会话持续 30 天。忘记密码可通过 `DUMBMONIT_RESET_PASSWORD=1` 重置：参见 [FAQ](../faq.md#i-lost-the-password)。

### 双因素认证 {#two-factor-authentication}

使用密码登录的账户可以添加第二因素：由验证器应用生成的六位基于时间的验证码（TOTP）——Aegis、FreeOTP、Google Authenticator、1Password、Bitwarden……**设置**会要求输入密码，显示可扫描的二维码（或可手动输入的密钥），并在你输入应用中的第一个验证码后启用第二因素。随后会一次性显示八个**恢复码**：请保存好，如果手机丢失，每个恢复码可登录一次。登录界面在密码之后会要求输入验证码（或恢复码）；输错五次验证码会取消本次尝试，需要从密码重新开始，而常规的登录速率限制会跨尝试持续计数。验证码只能使用一次：刚用过的那个（包括用来启用第二因素的那个）不能再次用来登录——请等待下一个。

**停用**会再次要求输入密码。恢复码不能单独重新生成：请停用后重新设置以获得新的一组。当手机和恢复码都丢失时，管理员可以在**用户**中重置另一个用户的第二因素（*重置 2FA*）——这会使该用户在所有地方登出，但不改动密码。密钥使用实例密钥加密存储；验证码经过哈希处理。单点登录账户的第二因素由身份提供方提供，而不是在这里。

管理员还会在本分区找到**安全日志**：登录与失败、密码和双因素变更、令牌和账户变更，并附客户端地址。它保留最近 5 000 条记录。

## 推送通知 {#push-notifications}

在此手机或电脑上的原生通知，即使 DumbMonit 已关闭也能收到：**在此设备上启用**，然后**发送测试**。每个账户（包括查看者）在这里管理自己的设备；哪些告警会送达它们，由告警 → 通知中的 **Web Push** 渠道决定。**i** 按钮概括了要求：HTTPS（或 localhost）、iPhone 和 iPad 上需添加到主屏幕，以及服务器必须能访问的推送服务域名。完整指南：[推送通知（PWA）](push-notifications.md)。

## 用户 {#users}

仅限管理员。可以登录的账户及其角色：

| 角色 | 读取全部内容 | 处理告警（确认、暂缓、忽略、维护窗口、清除历史） | 更改配置（设备、规则、渠道、状态页面、设置、备份、令牌、账户） |
|---|---|---|---|
| **查看者（Viewer）** | 是 | 否 | 否 |
| **操作员（Operator）** | 是 | 是 | 否 |
| **管理员（Admin）** | 是 | 是 | 是 |

查看者能看到每个页面，但所有会更改内容的控件都被隐藏。有几项即使是读取也仅限管理员：API 和代理令牌、状态页面订阅者邮箱，以及看起来像机密的设备选项（名称包含 `key`、`token`、`password`……的选项、HTTP 检查的额外请求头、`https://user:pass@host` 地址中的密码），非管理员读到的是 `***`。操作员是值班角色：具备告警控件，配置界面则显示 *Operator — config is admin only*。只有管理员可以创建账户或更改角色——操作员不能提升任何人，包括自己。*用户*、*单点登录*和安全日志分区仅限管理员。**添加用户**需要用户名、可选的显示名称、角色和密码；密码字段旁的按钮会生成一个随机密码。密码只显示一次，供你转交。

每一行显示角色、账户是用密码登录还是通过身份提供方登录、是否启用了双因素，以及上次登录时间。**编辑**可更改显示名称、角色和密码（重置会使该用户在所有地方登出，并一次性显示新密码）。**已启用**开关可在不删除账户的情况下将其暂停；账户有第二因素时会出现**重置 2FA**；**删除**会永久移除账户。服务器始终保留至少一个活跃的管理员，控件会体现这条规则，而不是将其作为错误报告：最后一个管理员不能被降级、停用或删除，你也不能停用或删除自己的账户。

## 单点登录 {#single-sign-on}

仅限管理员。通过 OpenID Connect 提供方（Authelia、Authentik、Keycloak、Pocket ID、Google Workspace……）登录。填写*提供方名称*（它会作为登录界面上“Continue with …”按钮的标签）、*issuer URL*——发现信息读取自 `{issuer}/.well-known/openid-configuration`——*client id*、*client secret*（加密存储，不再显示）以及浏览器访问 DumbMonit 的*公开 URL*。表单会根据该公开 URL 生成重定向 URI：复制它并在你的提供方处注册。

**测试发现**会读取提供方的配置而不让任何人登录，列出找到的端点，并在提供方既不使用 RS256 也不使用 ES256 签名时发出警告——这是 DumbMonit 仅接受的两种签名。在这里保存的设置优先于 `DUMBMONIT_OIDC_*` 环境变量，后者仅在没有保存任何设置时生效；**忽略已保存的设置**会清除它们，并在环境变量存在时回退到这些变量。

**高级。** 表单的其余部分位于*高级*之下：*Scopes* 指明向提供方请求什么，*Groups claim* 是令牌中列出用户所属群组的声明，*首次登录时创建账户*决定陌生人是否获得账户。它**默认关闭**：在你开启之前，只有已存在的账户才能登录。

**角色。** *管理员群组*列出其成员成为管理员的群组；*操作员群组*列出其他成员成为操作员的群组；其余所有人为查看者。两者都留空则继续在**用户**中管理角色。只填写*操作员群组*时，这些群组绝不会触及管理员角色：管理员仍是管理员，其他人成为操作员或查看者。角色在每次登录时重新评估，但最后一个活跃的管理员绝不会被降级。对应的环境变量是 `DUMBMONIT_OIDC_ADMIN_GROUPS` 和 `DUMBMONIT_OIDC_OPERATOR_GROUPS`。

**登录会落到哪个账户。** 首次登录之后，身份将通过提供方的 subject 被记住。首次登录时：

- 只有当提供方声明 `email_verified: true` 且该邮箱是账户的用户名时，才会关联到已有账户。`preferred_username` 或未验证的邮箱绝不会关联：在大多数提供方上，这些是由用户自己选择的，因此提供方的 `admin` 不能变成*你的* `admin`。
- 带密码的本地**管理员绝不会被自动关联**，即使邮箱已验证：登录会改为创建一个不同的账户。请继续用密码管理该管理员，或通过管理员群组创建单独的 SSO 管理员。
- 否则，若开启了*首次登录时创建账户*，则会创建新账户（用户名来自提供方，被占用时加后缀 `-1`、`-2`……）。若关闭，则只有上述已验证邮箱的关联才能登录。

**除非你选择，否则不创建账户。** 新安装默认关闭*首次登录时创建账户*，任何从未设置过它的配置也是如此——该选项出现之前保存的设置，或没有 `DUMBMONIT_OIDC_AUTO_CREATE` 的纯环境变量配置。早期版本把“从未设置”视为开启；单点登录面板现在会说明何时适用此默认值。你明确保存的值会原样保留。

## 代理 {#agents}

用于 [Linux、macOS、FreeBSD 和 Windows 代理](../devices/agent.md)的注册令牌。用一个名称（“File server”、“Home fleet”）创建一个：令牌只显示一次，并附带可直接复制的 Linux 和 Windows 安装命令。每条命令都带有此服务器所提供代理二进制文件的 SHA-256 校验和，安装程序会拒绝不匹配的下载；校验和也列在命令下方，便于手动比对。列表显示每个令牌的前缀、创建日期、上次使用和是否已被吊销。**吊销**会使所有使用该令牌的代理在下次推送时停止。

一个令牌可以注册多台机器。吊销它不会删除设备。令牌列表、创建和吊销仅限管理员；查看者和操作员看到的分区不含列表。

## API 与助手 {#api--assistants}

两者使用同一种令牌：MCP 客户端和 [REST API](../reference/api.md)。为令牌命名、选择其范围并创建——它只显示一次。**只读**令牌只能查看；**读写**令牌还能更改内容——静默设备、运行探测、添加或编辑设备、规则和渠道——但绝不能更改账户、登录设置或其他令牌。

在**连接**下，三个标签页存放代码片段，并在令牌仍显示在屏幕上时已填入该令牌：*Claude*（`claude mcp add` 命令和 `claude_desktop_config.json` 代码块）、*ChatGPT*（MCP 服务器 URL 和授权头；当此页面不是通过 HTTPS 提供时会给出警告——ChatGPT 从 OpenAI 的服务器发起连接，因此地址必须能从互联网访问）以及 *Cursor / 其他*，适用于任何支持带 bearer 头的 Streamable HTTP 的客户端，格式相同。**API 访问**以 `curl` 示例展示同一令牌在 REST API 上的用法，并指出 Prometheus 或 Grafana 用它抓取的路由。参见[连接助手](assistant.md)和[抓取 DumbMonit](../reference/metrics.md#scraping-dumbmonit)。

## 备份 {#backup}

三件事，按你遇到的顺序排列。

一条**你不可能错过的警告**：`/data/secret.key` 用来解密设备凭据，没有它的数据库副本恢复出来的实例无法与任何设备通信。当密钥改由 `DUMBMONIT_SECRET` 提供时，措辞会变化——此时没有文件可复制，必须由你的密码管理器来保存它。

**导出配置**会列出备份包将包含的内容，并按分区给出数量，然后要求输入两次口令。下载的文件包含此实例的所有凭据，仅用该口令加密：请把它放在你存放密码的地方。账户密码和 2FA 密钥默认不包含，除非你打开开关。

**恢复备份包**接收文件及其口令，并先显示一次**试运行**：按分区列出将创建、更新和保持不变的内容的表格，对无法安置的内容附带说明。在你按下*正式恢复*之前不会写入任何内容。

**定时本地备份**显示其是否开启、备份位置、上次运行及是否成功，以及保留的文件及其大小。**立即备份**会立刻写入一份——升级之前应当这样做。

这里的所有内容仅限管理员。参见[备份与恢复](../install/backup.md)。

## DumbMonit 自身 {#self-monitoring}

引擎当前的状态（调度器、SQLite 数据库、指标数据库），以及数据卷的可用空间、数据库大小，
还有内置 VictoriaMetrics 的重启次数。出现问题时，内置规则已经会提醒您。

下方是**外发心跳**：您提供的 URL（Healthchecks.io、Uptime Kuma 推送监控、Better Stack……），
DumbMonit 仅在自身正常时定期调用，这样当这台主机沉默时，外部就会有人发现。**测试**会立即发送一次调用；
**报告故障**会调用故障 URL 而不是保持沉默。URL 加密保存，不会再次显示，只显示其主机名。
只有管理员可以修改。参见 [Watching DumbMonit itself](../install/self-monitoring.md)。

## 报告 {#reports}

面向团队的定期可用性邮件：选择每周、每日或每月，指定日期、时间和时区、收件人及邮件渠道，然后**发送预览**查看结果。仅限管理员。参见[邮件报告](reports.md)。

## 外观 {#appearance}

三个图块，各自预览自己的主题：**系统**（跟随你的设备并随之切换）、**日间**（“图表纸”主题）和**夜间**（“雷达”主题）。选择保存在浏览器中。页眉的切换按钮和命令面板的*切换主题*在日间和夜间之间切换。

**打开墙面模式**位于该分区底部：仅显示公告栏，全屏，适合放在房间里的显示器上。++esc++ 退出，命令面板可在任何地方打开它——参见[墙面模式](overview.md#wall-mode)。

## 关于 {#about}

服务器版本，以及其两个存储的健康状况：数据库（设备设置和告警历史）和 VictoriaMetrics（图表中的所有测量数据），由 `GET /api/health` 报告，每 15 秒刷新一次。停止响应的存储会显示一条警告，附带错误信息和检查建议。该分区还链接到本文档，并注明许可证 Apache 2.0。
