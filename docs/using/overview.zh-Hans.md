# 概览页面 {#the-overview-page}

首页能在大约一秒钟内回答"一切都正常吗?",之后再让你按需深入
查看细节。

![概览](../assets/screenshots/overview-light.png){ loading=lazy }

## 简报 {#the-bulletin}

顶部的条带是你网络的一份天气简报。一句话概括整体情况:当没有
任何事需要处理时显示"晴朗无云。",否则显示需要处理事项的数量
("9 条提示,1 台不可达。")。下方的标牌统计上报中和不可达的
设备,标注上次检查的时间,以及三个数值:**上报中**、**需要
处理**、**预测**。

右侧的天气窗口会跟随网络状况变化:晴朗、多云、阴天或风暴,取决
于触发的告警数量及其严重程度,还有一只飞过的鸽子。在
`prefers-reduced-motion` 设置下,一切都保持静止。

该页面唯一的主操作是**添加设备**。

## 首次运行引导 {#the-first-run-guide}

在一个全新的实例上,简报下方的区域不是空的:它是一个三步引导——
添加一台设备、连接一种被告知的方式、检查消息是否送达。每一步
只需一次点击,每一步都可以单独跳过,**跳过引导**会一次性隐藏
全部三步。该选择会存储在实例上,因此换一个浏览器不会重新开始
引导。参见[添加第一台设备](../install/first-device.md#the-three-first-steps)。

## 需要处理 {#needs-you}

当前需要处理事项的列表,最严重的排在最前面:先是不可达的设备,
然后是按严重程度排列的触发中告警。每一行标注规则、设备、当前值、
持续了多久,以及它是否合并了多个序列(同一设备上四个文件系统
显示为"×4")。四种操作:**确认**(为这条告警确认 1 小时、4
小时、24 小时或直到解决——提醒会暂停,但解决时仍会通知你)、
**暂缓**(只隐藏这一条告警 1 小时、8 小时、1 天或直到解决)、
**忽略**(让这条规则永远不再对该设备发出告警,可撤销),以及
**打开设备**。

已确认和已暂缓的告警会移到列表下方各自更安静的分组中,并从
*需要处理*的计数中移除。被忽略的告警会直接消失——它不是"已知",
而是针对该设备被关闭了。参见[处理告警](alerts.md#getting-rid-of-an-alert)。

## 设备摘要 {#devices-summary}

一行文字:多少台设备、多少台在上报、多少台不可达,以及一个指向
完整设备页面的链接。概览页面从不列出具体设备:机架位于
[设备](devices.md)页面上。

## 预测与最近 24 小时 {#forecasts-and-last-24-hours}

**预测**显示的是预测结果而不是观测结果:季节性基线异常、"四天内
将用尽"的推算、PBS 空间耗尽估算,以及名称中带有"预测"字样的
规则。当某条基线仍在学习阶段时,相应条目会注明这一点。

**最近 24 小时**列出当天触发的转换记录,并附有指向告警页面完整
历史记录的链接。

## 大屏模式 {#wall-mode}

`/wall` 会以全屏方式单独显示简报,供房间监视器使用:那句话、
各项计数以及*需要处理*列表,每 20 秒刷新一次,并让屏幕保持
常亮。++esc++ 或点击**退出**会返回概览页面。可从命令面板
("大屏模式")打开,也可直接输入该 URL。它还可以播放从你手机
启动的音乐:参见[大屏模式与音乐](wall.md)。

![大屏模式](../assets/screenshots/wall-light.png){ loading=lazy }

## 安装到手机上 {#install-it-on-a-phone}

该界面提供一个 web manifest,因此手机可以把它添加到主屏幕:
iOS 上使用**分享 → 添加到主屏幕**,Android 上在 Chrome 菜单中
使用**安装应用**。之后它会在没有浏览器外框的情况下打开,并
使用手机设置的主题。

这里刻意**没有离线模式,也没有 service worker**。一个显示缓存
页面的监控屏幕,比一个明确表示连不上服务器的屏幕更糟糕:这整件
事的意义就在于你看到的内容是最新的。没有 worker,升级后的服务器
内容也会立即被提供,不存在需要清除的过期构建。

## 命令面板 {#command-palette}

在 macOS 上按 ++cmd+k++,其他系统按 ++ctrl+k++,会打开命令面板:
一个输入框,结果分为三组。

| 分组 | 条目 |
|---|---|
| 页面 | 概览、设备、告警、通知、状态页面、设置、大屏模式、文档 |
| 操作 | 添加设备、扫描我的网络、计划维护、添加通知渠道、新建状态页面、发布事件公告、切换主题 |
| 设备 | 每一台设备,带有其状态灯;按 ++enter++ 可打开它 |

## 导航 {#navigation}

顶部栏包含概览、设备、告警(带有需要处理事项的计数)、状态和
设置,以及面板快捷键和主题切换按钮。在手机上,它会变成底部的
标签栏,包含同样的五个条目。

- **概览**——简报:一切是否正常,以及什么需要处理。
- **设备**——机架;你监控的每一个来源。参见[设备页面](devices.md)。
- **告警**——正在触发的内容、计划维护、规则,以及通知渠道和
  策略。参见[告警页面](alerts.md)。
- **状态**——公开状态页面及其公告。参见[状态页面](status-pages.md)。
- **设置**——你的账户、用户和单点登录、代理和助手令牌、外观、
  关于。参见[设置](settings.md)。界面上没有任何内容仅通过颜色
  传达状态:标牌或状态灯总是会配有一个词(上报中、不可达、提示、
  警告、被父设备抑制、正在积累)。
