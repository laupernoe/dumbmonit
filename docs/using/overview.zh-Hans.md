# 概览页面

首页大约一秒内回答"一切正常吗?",之后让你按需深入查看。

## 状态横幅 {#the-bulletin}

顶部的横幅是一片固定的夜空:闪烁的星星、一弯新月,以及一只飞越夜空却从不降落的鸽子。夜空不会随天气变化;底部的一句话用文字说明现状。没有需要你处理的事时是"全部 146 个监控项正常。",否则是"pve-02 已宕机。"或"pve-02 需要看一眼。",随后用更轻的语气说明系统做了什么("3 个客户机已暂缓,告警已发送。")。点一下鸽子,它会翻一个滚。在 `prefers-reduced-motion` 下,鸽子不再出现,星星也保持静止。

## 首次运行引导 {#the-first-run-guide}

在一个全新的实例上,简报下方的区域不是空的:它是一个三步引导——
添加一个监控项、连接一种被告知的方式、检查消息是否送达。每一步
只需一次点击,每一步都可以单独跳过,**跳过引导**会一次性隐藏
全部三步。该选择会存储在实例上,因此换一个浏览器不会重新开始
引导。参见[添加第一个监控项](../install/first-device.md#the-three-first-steps)。

## 四项指标 {#the-figures}

横幅下方是四项指标:**正常监控项**(占总数的比例,附宕机与暂停数量)、**30 天可用率**、**p95 响应**以及**未处理告警**(严重与警告)。页眉中的时间范围决定 p95 和健康河流图。

## 需要处理的事项 {#what-needs-attention}

健康河流图旁的列表只包含当前出问题的事项,最严重的在前,每一行都带有快捷操作:确认或延后一条告警,或让某个监控项静音(小叉号)。没有任何故障时,鸽子在睡觉,卡片也会这样说明。底部用一行显示**未来一周**:未来七天内到期的内容。**查看全部**会打开[告警](alerts.md)。

## 健康河流图 {#the-health-river}

每个监控项一条带,时间范围的每个时间片一格,最差的监控项在最上方。概览显示前八个;**查看所有监控项**会打开“监控项”的[列表](devices.md)标签页。状态总是写在形状旁边(圆形为正常,菱形为降级,方形为宕机),绝不只靠颜色表示。在手机上,点按即可展开该图。

## 两张图表 {#charts}

再往下:整个监控群在该时间范围内的**响应时间**(p95 和中位数,以及最慢的监控项),以及**最近七天的告警**(已触发和已解决)。

## 大屏模式 {#wall-mode}

`/wall` 为房间里的显示器呈现一块看板:结论、时钟、五项指标、健康河、未解决的告警以及谁在值班。通过左侧菜单底部的 **Wall mode** 图标或命令面板打开;++esc++ 或 **Exit** 返回控制台。参见[大屏模式](wall.md)。

## 安装到手机上 {#install-it-on-a-phone}

该界面提供一个 web manifest,因此手机可以把它添加到主屏幕:
iOS 上使用**分享 → 添加到主屏幕**,Android 上在 Chrome 菜单中
使用**安装应用**。之后它会在没有浏览器外框的情况下打开,并
使用手机设置的主题。

这里刻意**没有离线模式,也没有 service worker**。一个显示缓存
页面的监控屏幕,比一个明确表示连不上服务器的屏幕更糟糕:这整件
事的意义就在于你看到的内容是最新的。没有 worker,升级后的服务器
内容也会立即被提供,不存在需要清除的过期构建。

## 命令面板 {#command-palette}

macOS 上按 ++cmd+k++,其他系统按 ++ctrl+k++,即可打开命令面板:一个输入框,结果分为三组。

| 分组 | 条目 |
|---|---|
| Pages | 概览、监控项、地图、告警、自动化、通知、指标浏览器、安全、状态页、报告、日志、设置、墙屏模式、文档 |
| Actions | Add a monitor, Scan my network, Schedule maintenance, Add notification channel, New status page, Announce an incident |
| Monitors | 每个监控项,带其状态指示灯;++enter++ 打开它 |

## 导航 {#navigation}

左侧一条窄的**菜单**列出四个入口:**概览**、**监控项**、**告警**(带需要处理的数量)和**状态**。底部是**设置**、**墙屏模式**、文档、GitHub 和你的账户。以前单独成页的内容,现在是这些入口中的标签页。页眉显示你所在的位置,以及暂停控制台自身刷新的**实时**开关、时间范围、命令面板和**添加监控项**。在手机上,菜单变成底部标签栏,包含核心入口和**更多**。

- **概览**:一切是否正常,以及哪些需要你处理。
- **监控项**:你监控的每个来源,分为四个标签页:**列表**、**地图**、**日志**和**安全**。参见[监控项](../monitors/index.md)。
- **告警**:五个标签页:**当前**、**历史**、**规则**、**自动化**和**值班**。参见[告警页面](alerts.md)。
- **状态**:**页面**(公开状态页)和**报告**。参见[状态](../status/index.md)。
- **设置**:你的账户、团队与访问、监控、通知、墙屏和系统。参见[设置](../settings/index.md)。

界面为深色,且界面上没有任何内容仅靠颜色传达状态:标记旁总有文字(Reporting、Unreachable、Advisory、Warning、Suppressed by parent、Building up)。
