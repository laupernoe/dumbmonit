# 大屏模式 {#wall-mode-and-music}

`/wall` 以全屏显示控制台自己的看板,适合在房间里常亮的显示器。它会自动刷新,并保持屏幕常亮。

从上到下:

- 用几个词给出的**结论**("All good"、"3 problems"),附日期、时钟以及上次更新的时间;
- 概览的**五项指标**:正常的监控项、30 天可用性、p95 响应时间、未解决的告警和平均恢复时间;
- **健康河**,看板上的主画面:每个监控项一条带,最差的在上;
- **未解决的告警**,最严重的在前;
- 当前**谁在值班**,附排班表和班次结束时间。

没有音乐、没有小组件:黑色背景、控制台自己的字体,状态写在形状旁边,绝不只靠颜色。

## 打开与退出

通过顶部栏的 **Wall mode** 图标、命令面板("Wall mode")或直接输入 URL 打开。++esc++ 或 **Exit** 返回控制台。受限于部分团队或客户的账户无法使用大屏模式,因为它显示整个设备群。

## 背景 {#backdrop}

大屏模式与控制台共享深色外观。**背景**按钮（右上角，Exit 旁边）可以在结论和时钟后方绘制一座[状态页](status-pages.md)的夜景城市：巴黎、纽约、东京或迪拜，或选择*自动*使用离浏览器时区最近的城市。默认关闭，并按浏览器记住；链接中的 `?city=paris`（或 `newyork`、`tokyo`、`dubai`、`none`）只为该显示器选择。天空跟随看板：一切正常时是星空，有提示时多云，有警告时雷雨。在手机上或标签页隐藏时，城市保持静止。已保存或链接中的 `zermatt` 现在会落到迪拜。
