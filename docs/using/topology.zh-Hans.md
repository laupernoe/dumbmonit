# 拓扑地图

**地图**页面（监控项页面上的**地图**按钮、命令面板中的*地图*，或 `/map`）用一张图
展示整个基础设施。无需手动录入：每条关联都来自 DumbMonit 已经掌握的信息。

## 关联从何而来

| 关联 | 来源 | 线型 |
|---|---|---|
| 依赖于 | 监控项上设置的**父级**，告警抑制也依据它。 | 实线 |
| 通过中继访问 | 在远程站点轮询监控项的**中继代理**。 | 长虚线 |
| 由虚拟化主机托管 | Proxmox VE、XCP-ng、Nutanix、vSphere 或 Linux 代理的 libvirt 模块在最近 30 分钟内报告的虚拟机/容器。 | 短虚线 |
| 线缆连接到（LLDP） | SNMP 交换机在某个端口上看到的 **LLDP 邻居**（`ethernet-switch` 配置）。 | 点线 |

只有当名称恰好指向一个监控项时（名称相同，或地址中的主机名相同，忽略域名），
虚拟机或 LLDP 邻居才会关联到该监控项。名称有歧义时宁可不建立关联，也不建立错误的关联。
没有对应监控项的虚拟机会作为独立方框显示在其虚拟化主机旁；未知的 LLDP 邻居不显示。
没有任何已知关联的监控项留在其所属文件夹中。

## 阅读地图

- 上游在左，依赖它的在右；每个文件夹一个分区。
- 每个方框显示类型图标、名称以及文字形式的状态。**故障**监控项有粗边框和 `!` 标记；
  其后方（经由父级、中继或虚拟化主机）的监控项标为**受影响**，边框为虚线：其告警被抑制。
- 单击打开该监控项；虚拟机方框打开其虚拟化主机。
- 拖动移动，滚轮或双指缩放，方向键、`+`、`-` 和 `0`（适应屏幕）。
- **显示**可将地图限定到某个文件夹或某个中继站点。
- 在手机上页面默认打开**列表**视图：同一棵树，带缩进。

## 导出与打印

**导出**提供 **SVG 图片**、**PNG 图片**（白底，带标题、范围、日期和图例），以及
**打印 / PDF（A4 横向）**和**（A3 横向）**：浏览器只打印这一页面，并缩放以适应纸张。

## API

`GET /api/topology` 返回节点、关联及每条关联的来源（所有角色可读，只读，不含地址）。
参见 [API 参考](../reference/api.md)。
