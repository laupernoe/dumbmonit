# Демо-устройство

Условное устройство, генерирующее измерения, чтобы изучить инструмент без
оборудования. Оборудование не требуется.

## Настройка

1. Задайте любое имя и подтвердите.
2. Поддельные измерения появятся сразу же, достаточно, чтобы освоиться с интерфейсом.

Адрес свободен (плейсхолдер говорит `demo`), учётные данные и опции не нужны.
Демо-устройство производит ряд `cpu_usage_percent`, поэтому к нему применяются
правила «Высокая загрузка CPU» и «Нетипичная загрузка CPU», и его можно
использовать как родителя или потомка в
[цепочке зависимостей](../alerting/index.md#dependency-suppression), чтобы
увидеть подавление в действии.

Для реальных измерений без выделенного оборудования направьте устройство SNMP
на любую машину с запущенным `snmpd`: см.
[Проверка без оборудования](../install/docker.md#testing-without-hardware).
