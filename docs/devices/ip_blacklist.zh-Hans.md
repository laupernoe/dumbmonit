# IP 段黑名单 {#ip-range-blocklist}

对一个公网 IPv4 段(最大 /24,即 256 个地址)中的每个地址,对照
[邮件服务器信誉](mail_blacklist.md#the-blocklists)中的 DNS 黑名单进行
检查:Spamhaus ZEN、Barracuda、SpamCop、Mailspike、UCEPROTECT Level 1、
PSBL 和 SpamRATS。监控项页面会说明有多少地址被列入、位于哪些名单,
并为每条收录记录给出指向其查询和移除页面的直接链接。

适用于办公室的公网地址段、托管服务商分配给你的地址块,或你的服务器
发信所用的地址:邻居被入侵的机器会带来一条收录记录,更严格的收件方
可能会将其扩大到整个地址段。

## 限制 {#limits}

- **每个监控项最大 /24。** 更大的地址段会被拒绝,并提示它包含多少个
  地址:请拆成多个 /24 监控项。每个地址对每个名单花费一次查询,而对
  成千上万个地址的扫描在它们看来像是滥用。
- **仅限 IPv4。** 在这些名单中,只有 Spamhaus ZEN 对 IPv6 作出应答,
  而且 IPv6 地址段无法逐个地址遍历。单个 IPv6 地址可以用
  [邮件服务器信誉](mail_blacklist.md)检查。
- **仅限公网地址。** 包含私有地址、共享地址(CGNAT)或文档用途地址的
  地址段会被拒绝:黑名单只了解公共互联网。
- **域名名单**(Spamhaus DBL、SURBL、URIBL)不适用于地址段。

## 解析器与节奏 {#resolvers-and-pace}

适用与[邮件服务器信誉](mail_blacklist.md#resolvers-refusals-and-timeouts)
相同的规则。Spamhaus 会拒绝公共解析器:其拒绝(`127.255.255.254`)
显示为配置错误,绝不显示为收录。未应答的名单是未知,绝不是干净。
请使用你自己的递归解析器,或使用免费的 Spamhaus DQS 密钥作为凭据。

一个 /24 需要将近两千次查询。它们按**每秒查询数**(默认 10)发送,
同时最多八个在途,整个地址段每个**刷新间隔**(默认 6 小时)检查一次;
其间的每次检查会再次显示最近一次的结果。地址段的第一次检查需要几分钟,
并在后台运行。

## 对照黑名单检查公网 IP 段 {#check-a-public-ip-range-against-the-blocklists}

1. 输入一个 IPv4 地址或最大 /24 的 CIDR 地址段,例如"198.51.100.0/24"(256 个地址)。更大的地址段会被拒绝:请拆成多个 /24 监控项。IPv6 地址段会被拒绝,因为只有 Spamhaus 对 IPv6 作出应答:请用邮件服务器信誉检查单个 IPv6 地址。

2. 与邮件服务器信誉一样,使用你自己的递归解析器:Spamhaus 会拒绝公共解析器;或者粘贴一个免费的 Spamhaus DQS 密钥作为凭据。一个 /24 需要将近两千次查询,默认按每秒 10 次发送并每 6 小时重复一次:请保持这个节奏,黑名单会封禁大规模扫描它们的解析器。

3. 地址段的第一次检查需要几分钟:监控项页面会说明它正在运行,随后显示有多少地址被列入、位于哪些名单,以及每条记录的移除链接。

!!! warning "警告"
    Spamhaus PBL 列出不应直接发送邮件的终端用户地址段(家庭宽带、动态地址池):在那里被收录只是一种策略,而不是滥用举报,只对运行着邮件服务器的地址才有意义。

## 监控内容 {#what-it-watches}

指标与[邮件服务器信誉](mail_blacklist.md#what-it-watches)相同,带前缀
`dumbmonit_blacklist_`,但不含反向 DNS、SPF 和 DMARC 相关的指标。为了
控制序列数量,`check` 只为被列入或某个名单未应答的地址写入;
`list_checked`、`list_listed` 和 `list_unknown` 按名单统计每个地址。

适用的[内置规则](../alerting/rules.md#dns-blocklists):被列入主要黑名单
和被列入黑名单。

## 凭据 {#credentials}

无,或一个 Spamhaus DQS 密钥。

地址:一个 IPv4 地址或最大 /24 的 CIDR 地址段。选项:解析器、
名单(默认全部地址名单)、刷新间隔(6 小时)、每秒查询数(10)和
每次查询的超时(5 秒)。
