# Чёрные списки для диапазона IP

Каждый адрес публичного диапазона IPv4 размером до /24 (256 адресов) проверяется
по чёрным спискам DNS из раздела [Репутация почтового сервера](mail_blacklist.md#the-blocklists):
Spamhaus ZEN, Barracuda, SpamCop, Mailspike, UCEPROTECT Level 1, PSBL и
SpamRATS. Страница монитора показывает, сколько адресов числится в списках, в
каких именно, и даёт прямую ссылку на страницу проверки и удаления для каждой
записи.

Полезно для публичного диапазона офиса, блока, выданного вам хостинг-провайдером,
или адресов, с которых отправляют почту ваши серверы: взломанная машина соседа
получает запись, которую более строгий получатель может распространить на весь
диапазон.

## Ограничения

- **Не более /24 на монитор.** Больший диапазон отклоняется с сообщением о том,
  сколько в нём адресов: разделите его на несколько мониторов /24. Каждый адрес
  стоит одного запроса к каждому списку, а прочёсывание тысяч адресов выглядит
  для них как злоупотребление.
- **Только IPv4.** Из этих списков для IPv6 отвечает только Spamhaus ZEN, а
  диапазон IPv6 нельзя обойти адрес за адресом. Один адрес IPv6 можно проверить
  через [Репутация почтового сервера](mail_blacklist.md).
- **Только публичные адреса.** Диапазон, включающий частный, общий (CGNAT) или
  документационный адрес, отклоняется: чёрные списки знают только публичный
  Интернет.
- **Списки доменов** (Spamhaus DBL, SURBL, URIBL) к диапазону не применяются.

## Резолверы и темп

Действуют те же правила, что и для [Репутация почтового сервера](mail_blacklist.md#resolvers-refusals-and-timeouts).
Spamhaus отказывает публичным резолверам: его отказ (`127.255.255.254`)
показывается как ошибка конфигурации, а не как внесение в список. Список, не
ответивший, считается неизвестным, но не чистым. Используйте собственный
рекурсивный резолвер или бесплатный ключ Spamhaus DQS как учётные данные.

/24 требует почти двух тысяч запросов. Они отправляются со скоростью **Queries
per second** (по умолчанию 10), не более восьми одновременно, а весь диапазон
проверяется раз в **Refresh interval** (по умолчанию 6 часов); между проверками
при каждой проверке показывается последний результат. Первая проверка диапазона
занимает несколько минут и выполняется в фоне.

## Проверка публичного диапазона IP по чёрным спискам

1. Введите адрес IPv4 или диапазон CIDR до /24, например "198.51.100.0/24" (256 адресов). Больший диапазон отклоняется: разделите его на несколько мониторов /24. Диапазоны IPv6 отклоняются, так как для IPv6 отвечает только Spamhaus: проверяйте отдельный адрес IPv6 через Репутацию почтового сервера.

2. Используйте собственный рекурсивный резолвер, как для Репутации почтового сервера: Spamhaus отказывает публичным резолверам, либо вставьте бесплатный ключ Spamhaus DQS как учётные данные. /24 требует почти двух тысяч запросов, отправляемых со скоростью 10 в секунду и повторяемых по умолчанию каждые 6 часов: соблюдайте этот темп, чёрные списки банят резолверы, которые их прочёсывают.

3. Первая проверка диапазона занимает несколько минут: страница монитора сообщает, что она выполняется, затем показывает, сколько адресов числится в списках, в каких, и ссылку на удаление для каждого.

!!! warning
    Spamhaus PBL вносит диапазоны конечных пользователей, которые не должны отправлять почту напрямую (домашние подключения, динамические пулы): запись там — это политика, а не жалоба на злоупотребление, и она важна только для адреса, на котором работает почтовый сервер.

## Что отслеживается

Те же метрики, что у [Репутация почтового сервера](mail_blacklist.md#what-it-watches),
с префиксом `dumbmonit_blacklist_`, без метрик обратного DNS, SPF и DMARC.
Чтобы число рядов оставалось небольшим, `check` записывается только для адреса,
который числится в списке или на который список не ответил; `list_checked`,
`list_listed` и `list_unknown` считают каждый адрес по спискам.

Применяемые [встроенные правила](../alerting/rules.md#dns-blocklists): Listed
on a major blocklist и Listed on a blocklist.

## Учётные данные

Нет, или ключ Spamhaus DQS.

Адрес: адрес IPv4 или диапазон CIDR до /24. Параметры: Resolver,
Lists (по умолчанию все списки адресов), Refresh interval (6 часов),
Queries per second (10) и Timeout per query (5 с).
