# ИБП через NUT

ИБП, подключённый к NAS, Raspberry Pi или серверу по USB, обычно
отслеживается Network UPS Tools (NUT): его демон, `upsd`, публикует то, что
сообщает ИБП, на TCP-порту 3493. DumbMonit читает этот сервер, как любой
клиент NUT: работает ли ИБП от сети или от батареи, разряжена или изношена
батарея, заряд, оставшееся время работы, нагрузка, входное напряжение и
возраст батареи. Один сервер часто публикует несколько ИБП; все они
считываются за одно соединение, и каждый ряд несёт имя своего ИБП.

Для ИБП с собственной сетевой картой тип [устройство SNMP](snmp.md) читает
стандартный UPS-MIB вместо этого.

## Что отслеживается

Все метрики с префиксом `dumbmonit_nut_` и несут метку `ups` — имя ИБП из
`ups.conf` («ups» на NAS Synology, «qnapups» на QNAP). Переменная, которую
ИБП не публикует, не даёт ряда.

| Метрика | Что | Метки |
|---|---|---|
| `ups_on_line`, `ups_on_battery`, `ups_low_battery`, `ups_high_battery`, `ups_replace_battery`, `ups_charging`, `ups_discharging`, `ups_bypass`, `ups_calibrating`, `ups_off`, `ups_overload`, `ups_trim`, `ups_boost`, `ups_forced_shutdown`, `ups_alarm` | Флаги `ups.status` (`OL`, `OB`, `LB`, `HB`, `RB`, `CHRG`, `DISCHRG`, `BYPASS`, `CAL`, `OFF`, `OVER`, `TRIM`, `BOOST`, `FSD`, `ALARM`): 1, когда установлен, иначе 0, все при каждом чтении | `ups` |
| `ups_status_info` | значение 1, необработанный `ups.status` | `ups`, `status` |
| `battery_charge_percent`, `battery_charge_low_percent` | заряд, и заряд, ниже которого ИБП сообщает о низком заряде батареи | `ups` |
| `battery_runtime_seconds`, `battery_runtime_low_seconds` | оставшееся время работы от батареи при текущей нагрузке, и время работы при низком заряде | `ups` |
| `battery_voltage_volts`, `battery_temperature_celsius` | | `ups` |
| `battery_age_seconds` | время с `battery.date` (установки или замены), либо иначе `battery.mfr.date` | `ups`, `source` (`installed`, `manufactured`) |
| `input_voltage_volts`, `input_voltage_nominal_volts`, `input_frequency_hertz` | сторона сети; 0 В во время отключения | `ups` |
| `output_voltage_volts`, `output_frequency_hertz` | сторона нагрузки | `ups` |
| `ups_load_percent` | нагрузка, в процентах от ёмкости ИБП | `ups` |
| `ups_realpower_watts`, `ups_realpower_nominal_watts`, `ups_power_va`, `ups_power_nominal_va` | потребляемая мощность и номинал, когда ИБП их сообщает | `ups` |
| `ups_temperature_celsius` | | `ups` |
| `ups_self_test_failed` | 1, когда последний самотест (`ups.test.result`) сообщает ошибку или предупреждение, 0 — когда пройден; отсутствует, если тест не запускался | `ups`, `result` |
| `ups_info` | значение 1 | `ups`, `manufacturer`, `model`, `firmware`, `driver`, `battery_type`, `description` |
| `ups_data_stale` | 1, когда `upsd` отвечает, но не имеет свежих данных от ИБП (`DATA-STALE`, `DRIVER-NOT-CONNECTED`) | `ups` |
| `ups_driver_connected` | 0, когда драйвер NUT этого ИБП не запущен | `ups` |
| `server_ups` | число ИБП, публикуемых сервером | |
| `server_info` | значение 1 | `version` |

Серийные номера никогда не помещаются в метку. За один сервер считывается не
более 32 ИБП.

Применяемые [встроенные правила](../alerting/rules.md#ups-behind-nut): «ИБП
на батарее (NUT)», «Низкий заряд батареи ИБП (NUT)», «Требуется замена
батареи ИБП (NUT)», «Высокая нагрузка ИБП (NUT)», «Малое время работы ИБП
(NUT)», «Данные ИБП устарели (NUT)», плюс «Устройство недоступно», когда сам
сервер NUT перестаёт отвечать.

## Страница устройства

Панель над графиками читает то, что сохранила проверка; открытие страницы
никогда не подключается к серверу NUT. Одна карточка на ИБП: его состояние
словами (от сети, от батареи, низкий заряд, замена батареи, bypass,
перегрузка…), заряд, оставшееся время работы, нагрузка, входное напряжение и
возраст батареи.

## Дать DumbMonit читать сервер NUT

1. Найдите сервер NUT: машина, к которой подключён ИБП (NAS, Raspberry Pi, сервер), запускает upsd на TCP-порту 3493. С хоста DumbMonit проверьте, что он отвечает, и запомните имена своих ИБП.

    ```
    printf 'LIST UPS\nLOGOUT\n' | nc nas.lan 3493
    ```

    С установленными клиентскими инструментами NUT `upsc -l nas.lan` даёт тот же список.

2. При обычной установке NUT сделайте так, чтобы upsd слушал на адресе, доступном хосту DumbMonit: добавьте эту строку в upsd.conf, откройте TCP-порт 3493 в файрволе для хоста DumbMonit, и перезапустите upsd. Для чтения учётная запись не нужна: upsd позволяет любому принятому хосту читать переменные, и ничего не меняет без пользователя, у которого есть на это право.

    ```
    LISTEN 0.0.0.0 3493
    ```

3. На NAS тот же переключатель называется иначе. Synology DSM: Control Panel → Hardware & Power → UPS, отметьте Enable network UPS server, и добавьте хост DumbMonit в Permitted DiskStation Devices; ИБП называется ups. QNAP: страница UPS в Control Panel, Enable network UPS master, с хостом DumbMonit среди разрешённых адресов; ИБП называется qnapups. TrueNAS: служба UPS с отметкой Remote Monitor.

4. Необязательно: DumbMonit отправляет имя пользователя и пароль только если вы его вводите, а upsd не требует их для чтения. Если ваша политика требует именовать каждого клиента, добавьте пользователя без действий или instcmd в upsd.users, с длинным случайным паролем, и перезапустите upsd.

    ```
    [dumbmonit]
    password = a-long-random-password
    ```

5. В DumbMonit введите адрес сервера NUT, например «nas.lan». Отслеживается каждый публикуемый им ИБП; чтобы отслеживать только некоторые, перечислите их имена в опции UPS.

6. DumbMonit только читает: он отправляет LIST UPS и LIST VAR, никогда LOGIN, SET, INSTCMD или FSD, так что сервер никогда не засчитывает его как вторичного клиента, который нужно ждать перед выключением.

!!! warning
    DumbMonit наблюдает за ИБП; он ничего не выключает. Машины, которые питает ИБП, всё равно нуждаются в собственном клиенте NUT (upsmon), чтобы корректно выключиться при разряде батареи.

## Учётные данные

| Учётные данные | Поля |
|---|---|
| Без аутентификации | По умолчанию: `upsd` позволяет любому принятому хосту читать переменные ИБП. |
| Имя пользователя / пароль upsd | Отправляется с `USERNAME` и `PASSWORD` перед чтением. `upsd` проверяет их только для команд, которые DumbMonit никогда не отправляет. |

Адрес: имя хоста или IP (`nas.lan`), `host:port`, или форма `ups@host` от
`upsc`, из которой сохраняется только хост. Опции: порт (3493), ИБП для
наблюдения (по умолчанию все) и таймаут на обмен (10 с).

Отклонённое соединение или отсутствие ответа считается недоступностью
устройства. `ACCESS-DENIED` показывается как ошибка учётных данных, а имя
ИБП, которое сервер не публикует, — как ошибка конфигурации; ни то, ни
другое не будит никого ночью. Соединение обычное TCP: `STARTTLS` не
используется, и ничто из читаемого не секретно.
