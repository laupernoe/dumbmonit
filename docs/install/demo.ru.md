# Запуск демо-инстанса

Публичная демонстрация на **[demo.dumbmonit.app](https://demo.dumbmonit.app)**
— это обычный образ DumbMonit, запущенный с `DUMBMONIT_DEMO=1`. Вы можете
запустить то же самое сами — чтобы показать DumbMonit команде перед настоящей
установкой, или чтобы разместить витрину на собственном сайте.

!!! warning "Никогда на настоящем томе данных"
    Демо-режим **пересоздаёт базу данных при каждом запуске**. Дайте ему
    собственный том или вообще без тома: направленный на `/data` настоящего
    инстанса, он заменит ваши устройства, правила и историю условным парком
    устройств.

## Что делает демо-режим

- **Вход `demo` / `demo`.** Страница входа сообщает об этом и заполняет поля
  в один клик. Учётная запись видит каждый экран, который видит администратор.
- **Только чтение.** Каждое изменение — устройства, правила, заглушения,
  подтверждения, каналы, токены, пользователи, настройки, резервные копии и
  восстановления, сканирования обнаружения, регистрация агентов, инструменты
  записи конечной точки ассистента — отклоняется сервером с кодом `403` и
  `{"error": "This is a read-only demo…", "demo": true}`. Вход и выход — это
  единственные разрешённые записи. Интерфейс показывает сообщение там, где
  произошёл клик.
- **Фиксированный, условный парк.** При запуске база данных создаётся заново и
  заполняется небольшой домашней лабораторией в домене `*.home.arpa`: кластер
  Proxmox VE, NAS Synology, Proxmox Backup Server, TrueNAS, файрвол OPNsense,
  сервер Redfish с отказавшей деталью, несколько проверок HTTP, TLS и ping,
  хост с агентом и страница статуса. Устройства отвечают через поддельные
  обработчики внутри сервера, привязанные к `127.0.0.1` и воспроизводящие
  записанные ответы API, так что реальные сборщики данных и панели устройств
  работают как обычно. Перезапуск даёт тот же парк.
- **Семь дней истории.** Синтетические метрики записываются в
  VictoriaMetrics при запуске, поэтому графики, *Last 7 days*, прогнозы и
  история оповещений заполнены, а несколько оповещений срабатывает, чтобы в
  *Needs you* было что показать.
- **Ничего не уходит за пределы сервера.** Уведомления никогда не отправляются,
  и ни одна проверка не идёт на адрес, введённый посетителем.
- **Вводный тур** открывается после первого входа; баннер открывает его снова.

Ограничение частоты входа работает как обычно. Разместите демо за обычным
обратным прокси с HTTPS и задайте `DUMBMONIT_COOKIE_SECURE=1` и
`DUMBMONIT_TRUSTED_PROXIES`, как для любого публичного инстанса.

## Запуск

```bash
docker run -d --name dumbmonit-demo -p 8080:8080 \
  -e DUMBMONIT_DEMO=1 \
  ghcr.io/laupernoe/dumbmonit:latest
```

Или с Compose, без тома, чтобы каждый перезапуск начинался с чистого листа:

```yaml
services:
  dumbmonit-demo:
    image: ghcr.io/laupernoe/dumbmonit:latest
    restart: unless-stopped
    ports:
      - "8080:8080"
    environment:
      DUMBMONIT_DEMO: "1"
```

Регулярно скачивайте новый образ (или дайте это делать инструменту типа
Watchtower): тогда демо всегда показывает последний релиз с теми же данными.
