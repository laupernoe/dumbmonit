# 开始使用

安装 DumbMonit,添加最初要监控的对象,并让它持续运行。本节讲服务器一侧:Docker、HTTPS、更新和备份。容器启动后由应用接手:**概览**页上的首次使用向导会带您完成第一个监控项和第一条通知。

在应用中,备份、HTTPS、更新以及服务器自身的健康状况位于**设置 › 系统**。

| 步骤 | 您要做的事 | 页面 |
|---|---|---|
| **安装** | 运行容器、在前面加上 HTTPS、更新、核对下载的内容 | [Docker](docker.md)、[HTTPS 与加密](https.md)、[代理通道安全](agent-security.md)、[更新](update.md)、[验证发布版本](verify.md)、[运行演示实例](demo.md) |
| **上手第一步** | 熟悉界面、添加第一个监控项、连接远程站点 | [界面与设置向导](../using/product-modes.md)、[添加第一个监控项](first-device.md)、[监控远程站点](remote-site.md) |
| **日常运维** | 备份与恢复、监视 DumbMonit 自身、查看服务器日志 | [备份与恢复](backup.md)、[监视 DumbMonit 自身](self-monitoring.md)、[服务器日志](logs.md) |

然后按应用的菜单继续: [概览](../overview/index.md), [监控项](../monitors/index.md), [告警](../alerting/index.md), [状态](../status/index.md) 和 [设置](../settings/index.md).
