# Get started

Install DumbMonit, add the first things to watch, and keep it running. This section is the server side: Docker, HTTPS, updates and backups. Once the container is up, the app takes over: the first-run guide on **Overview** walks you through the first monitor and the first notification.

In the app, backups, HTTPS, updates and the server's own health live in **Settings › System**.

| Step | What you do | Pages |
|---|---|---|
| **Install** | Run the container, put HTTPS in front, update, check what you downloaded | [Docker](docker.md), [HTTPS and encryption](https.md), [Agent channel security](agent-security.md), [Update](update.md), [Verify a release](verify.md), [Run a demo instance](demo.md) |
| **First steps** | Find your way around the interface, add a first monitor, reach a remote site | [Interface and setup wizard](../using/product-modes.md), [Add your first monitor](first-device.md), [Monitor a remote site](remote-site.md) |
| **Keep it running** | Back up and restore, watch DumbMonit itself, read the server's logs | [Backup and restore](backup.md), [Watching DumbMonit itself](self-monitoring.md), [Server logs](logs.md) |

Then follow the menu of the app: [Overview](../overview/index.md), [Monitors](../monitors/index.md), [Alerts](../alerting/index.md), [Status](../status/index.md) and [Settings](../settings/index.md).
