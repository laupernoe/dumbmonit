# Settings

Everything you configure once and then rarely touch. In the app it is **Settings** at the foot of the left menu, in seven tabs, each with its own address; the search box over them finds a section by name. Some tabs are for administrators only.

| Tab | What is in it | Read |
|---|---|---|
| **General** | Instance name, language, time zone, the setup wizard | [Interface and setup wizard](../using/product-modes.md) |
| **My account** | Appearance, password, two-factor, passkeys, push notifications, your on-call contacts and hours | [Passkeys](../using/passkeys.md), [Push notifications (PWA)](../using/push-notifications.md), [On-call](../alerting/oncall.md) |
| **Team & access** | Users, teams, clients, single sign-on, LDAP, SAML, SCIM | [Teams and permissions](../using/teams.md), [LDAP / Active Directory](../using/ldap.md), [SAML 2.0](../using/saml.md), [SCIM provisioning](../using/scim.md), [Multi-client (MSP)](../using/msp.md) |
| **Monitoring** | Agents, integration packs, security score, locations | [Linux, macOS, FreeBSD and Windows agent](../devices/agent.md), [Integration packs](../packs/index.md), [Security score](../using/security-score.md), [World map](../using/world-map.md) |
| **Notifications** | Channels and the notification policy | [Notification channels](../notifications.md), [Notification policy](../alerting/notifications.md) |
| **Wall display** | What the wall shows and its music | [Wall mode and music](../using/wall.md) |
| **System** | Backup, configuration files, DumbMonit itself, HTTPS, storage, server logs, API and assistants, About | [Backup and restore](../install/backup.md), [HTTPS and encryption](../install/https.md), [Watching DumbMonit itself](../install/self-monitoring.md), [Server logs](../install/logs.md), [Connect an assistant (MCP)](../using/assistant.md), [Configuration files (GitOps)](../using/config-files.md) |

[All settings](../using/settings.md) describes every section, tab by tab.
