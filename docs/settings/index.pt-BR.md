# Configurações

Tudo o que se configura uma vez e depois raramente se mexe. No aplicativo são as **Configurações**, no pé do menu da esquerda, em sete abas com endereço próprio; a caixa de busca acima encontra uma seção pelo nome. Algumas abas são só para administradores.

| Aba | O que contém | Ler |
|---|---|---|
| **Geral** | Nome da instância, idioma, fuso horário, o assistente de configuração | [Interface e assistente de configuração](../using/product-modes.md) |
| **Minha conta** | Aparência, senha, dois fatores, chaves de acesso, notificações push, seus contatos e horários de plantão | [Chaves de acesso (passkeys)](../using/passkeys.md), [Notificações push (PWA)](../using/push-notifications.md), [Plantões](../alerting/oncall.md) |
| **Equipe e acesso** | Usuários, equipes, clientes, login único, LDAP, SAML, SCIM | [Equipes e permissões](../using/teams.md), [LDAP / Active Directory](../using/ldap.md), [SAML 2.0](../using/saml.md), [Provisionamento SCIM](../using/scim.md), [Multicliente (MSP)](../using/msp.md) |
| **Monitoramento** | Agentes, pacotes de integração, pontuação de segurança, localizações | [Agente para Linux, macOS, FreeBSD e Windows](../devices/agent.md), [Pacotes de integração](../packs/index.md), [Pontuação de segurança](../using/security-score.md), [Mapa-múndi](../using/world-map.md) |
| **Notificações** | Canais e política de notificações | [Canais de notificação](../notifications.md), [Política de notificações](../alerting/notifications.md) |
| **Tela de parede** | O que a parede mostra e a sua música | [Modo parede e música](../using/wall.md) |
| **Sistema** | Backup, arquivos de configuração, o próprio DumbMonit, HTTPS, armazenamento, logs do servidor, API e assistentes, Sobre | [Backup e restauração](../install/backup.md), [HTTPS e criptografia](../install/https.md), [Monitorar o próprio DumbMonit](../install/self-monitoring.md), [Logs do servidor](../install/logs.md), [Conectar um assistente (MCP)](../using/assistant.md), [Arquivos de configuração (GitOps)](../using/config-files.md) |

[Todas as configurações](../using/settings.md) descreve cada seção, aba por aba.
