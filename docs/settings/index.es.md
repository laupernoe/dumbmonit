# Ajustes

Todo lo que se configura una vez y luego se toca poco. En la aplicación son los **Ajustes**, al pie del menú izquierdo, en siete pestañas con su propia dirección; el cuadro de búsqueda encima encuentra una sección por su nombre. Algunas pestañas son solo para administradores.

| Pestaña | Qué contiene | Leer |
|---|---|---|
| **General** | Nombre de la instancia, idioma, zona horaria, el asistente de configuración | [Interfaz y asistente de configuración](../using/product-modes.md) |
| **Mi cuenta** | Apariencia, contraseña, doble factor, claves de acceso, notificaciones push, sus contactos y horarios de guardia | [Claves de acceso (passkeys)](../using/passkeys.md), [Notificaciones push (PWA)](../using/push-notifications.md), [Guardias](../alerting/oncall.md) |
| **Equipo y acceso** | Usuarios, equipos, clientes, inicio de sesión único, LDAP, SAML, SCIM | [Equipos y permisos](../using/teams.md), [LDAP / Active Directory](../using/ldap.md), [SAML 2.0](../using/saml.md), [Aprovisionamiento SCIM](../using/scim.md), [Multicliente (MSP)](../using/msp.md) |
| **Supervisión** | Agentes, packs de integración, puntuación de seguridad, ubicaciones | [Agente para Linux, macOS, FreeBSD y Windows](../devices/agent.md), [Packs de integración](../packs/index.md), [Puntuación de seguridad](../using/security-score.md), [Mapa mundial](../using/world-map.md) |
| **Notificaciones** | Canales y política de notificaciones | [Canales de notificación](../notifications.md), [Política de notificaciones](../alerting/notifications.md) |
| **Pantalla de pared** | Lo que muestra la pared y su música | [Modo pared y música](../using/wall.md) |
| **Sistema** | Copia de seguridad, archivos de configuración, el propio DumbMonit, HTTPS, almacenamiento, registros del servidor, API y asistentes, Acerca de | [Copia de seguridad y restauración](../install/backup.md), [HTTPS y cifrado](../install/https.md), [Vigilar DumbMonit mismo](../install/self-monitoring.md), [Registros del servidor](../install/logs.md), [Conectar un asistente (MCP)](../using/assistant.md), [Archivos de configuración (GitOps)](../using/config-files.md) |

[Todos los ajustes](../using/settings.md) describe cada sección, pestaña por pestaña.
