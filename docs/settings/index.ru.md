# Настройки

Всё, что настраивается один раз и потом редко меняется. В приложении это **Настройки** внизу левого меню, в семи вкладках, у каждой свой адрес; поле поиска над ними находит раздел по названию. Некоторые вкладки только для администраторов.

| Вкладка | Что в ней | Читать |
|---|---|---|
| **Общие** | Имя экземпляра, язык, часовой пояс, мастер настройки | [Интерфейс и мастер настройки](../using/product-modes.md) |
| **Моя учётная запись** | Оформление, пароль, двухфакторная аутентификация, ключи доступа, push-уведомления, ваши контакты и часы дежурств | [Ключи доступа (passkeys)](../using/passkeys.md), [Push-уведомления (PWA)](../using/push-notifications.md), [Дежурства](../alerting/oncall.md) |
| **Команда и доступ** | Пользователи, команды, клиенты, единый вход, LDAP, SAML, SCIM | [Команды и права](../using/teams.md), [LDAP / Active Directory](../using/ldap.md), [SAML 2.0](../using/saml.md), [Подготовка учётных записей SCIM](../using/scim.md), [Несколько клиентов (MSP)](../using/msp.md) |
| **Мониторинг** | Агенты, пакеты интеграции, оценка безопасности, расположения | [Агент для Linux, macOS, FreeBSD и Windows](../devices/agent.md), [Пакеты интеграции](../packs/index.md), [Оценка безопасности](../using/security-score.md), [Карта мира](../using/world-map.md) |
| **Уведомления** | Каналы и политика уведомлений | [Каналы уведомлений](../notifications.md), [Политика уведомлений](../alerting/notifications.md) |
| **Экран стены** | Что показывает стена и её музыка | [Режим стены и музыка](../using/wall.md) |
| **Система** | Резервные копии, файлы конфигурации, сам DumbMonit, HTTPS, хранилище, журналы сервера, API и ассистенты, О программе | [Резервное копирование и восстановление](../install/backup.md), [HTTPS и шифрование](../install/https.md), [Наблюдение за самим DumbMonit](../install/self-monitoring.md), [Журналы сервера](../install/logs.md), [Подключение ассистента (MCP)](../using/assistant.md), [Файлы конфигурации (GitOps)](../using/config-files.md) |

[Все настройки](../using/settings.md) описывает каждый раздел, вкладка за вкладкой.
