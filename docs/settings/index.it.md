# Impostazioni

Tutto ciò che si configura una volta e poi si tocca di rado. Nell'app sono le **Impostazioni**, in fondo al menu di sinistra, in sette schede ciascuna con il proprio indirizzo; la casella di ricerca sopra trova una sezione dal nome. Alcune schede sono riservate agli amministratori.

| Scheda | Cosa contiene | Leggi |
|---|---|---|
| **Generale** | Nome dell'istanza, lingua, fuso orario, la procedura guidata di configurazione | [Interfaccia e procedura guidata](../using/product-modes.md) |
| **Il mio account** | Aspetto, password, due fattori, passkey, notifiche push, i tuoi contatti e orari di reperibilità | [Passkey](../using/passkeys.md), [Notifiche push (PWA)](../using/push-notifications.md), [Reperibilità](../alerting/oncall.md) |
| **Team e accesso** | Utenti, team, clienti, single sign-on, LDAP, SAML, SCIM | [Team e permessi](../using/teams.md), [LDAP / Active Directory](../using/ldap.md), [SAML 2.0](../using/saml.md), [Provisioning SCIM](../using/scim.md), [Multi-cliente (MSP)](../using/msp.md) |
| **Monitoraggio** | Agent, pacchetti di integrazione, punteggio di sicurezza, sedi | [Agent per Linux, macOS, FreeBSD e Windows](../devices/agent.md), [Pacchetti di integrazione](../packs/index.md), [Punteggio di sicurezza](../using/security-score.md), [Mappa del mondo](../using/world-map.md) |
| **Notifiche** | Canali e criteri di notifica | [Canali di notifica](../notifications.md), [Criteri di notifica](../alerting/notifications.md) |
| **Schermo a parete** | Cosa mostra la parete e la sua musica | [Modalità parete e musica](../using/wall.md) |
| **Sistema** | Backup, file di configurazione, DumbMonit stesso, HTTPS, archiviazione, log del server, API e assistenti, Informazioni | [Backup e ripristino](../install/backup.md), [HTTPS e cifratura](../install/https.md), [Sorvegliare DumbMonit stesso](../install/self-monitoring.md), [Log del server](../install/logs.md), [Collegare un assistente (MCP)](../using/assistant.md), [File di configurazione (GitOps)](../using/config-files.md) |

[Tutte le impostazioni](../using/settings.md) descrive ogni sezione, scheda per scheda.
