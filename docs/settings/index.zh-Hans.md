# 设置

只需配置一次、之后很少再动的一切。在应用中是位于左侧菜单底部的**设置**,分为七个标签页,各有自己的地址;上方的搜索框可按名称找到某个部分。部分标签页仅限管理员。

| 标签页 | 包含内容 | 阅读 |
|---|---|---|
| **常规** | 实例名称、语言、时区、设置向导 | [界面与设置向导](../using/product-modes.md) |
| **我的账户** | 外观、密码、双因素、通行密钥、推送通知、您的值班联系方式和时间 | [通行密钥(passkeys)](../using/passkeys.md)、[推送通知(PWA)](../using/push-notifications.md)、[值班](../alerting/oncall.md) |
| **团队与访问** | 用户、团队、客户、单点登录、LDAP、SAML、SCIM | [团队与权限](../using/teams.md)、[LDAP / Active Directory](../using/ldap.md)、[SAML 2.0](../using/saml.md)、[SCIM 配置同步](../using/scim.md)、[多客户(MSP)](../using/msp.md) |
| **监控** | 代理、集成包、安全评分、位置 | [Linux、macOS、FreeBSD 和 Windows 代理](../devices/agent.md)、[集成包](../packs/index.md)、[安全评分](../using/security-score.md)、[世界地图](../using/world-map.md) |
| **通知** | 渠道和通知策略 | [通知渠道](../notifications.md)、[通知策略](../alerting/notifications.md) |
| **墙屏显示** | 墙屏显示的内容及其音乐 | [墙屏模式与音乐](../using/wall.md) |
| **系统** | 备份、配置文件、DumbMonit 自身、HTTPS、存储、服务器日志、API 与助手、关于 | [备份与恢复](../install/backup.md)、[HTTPS 与加密](../install/https.md)、[监视 DumbMonit 自身](../install/self-monitoring.md)、[服务器日志](../install/logs.md)、[连接助手(MCP)](../using/assistant.md)、[配置文件(GitOps)](../using/config-files.md) |
