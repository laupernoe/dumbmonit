# Баннер на сайте

Показывайте на собственном сайте баннер, когда сервисы недоступны («2 сервиса
недоступны»), на основе опубликованной [страницы статуса](../using/status-pages.md).
Когда всё в порядке, баннер остаётся скрытым, если вы не попросите показывать
его всегда («Все системы работают»).

Три способа добавить его, от самого простого до самого контролируемого.
Готовые к копированию файлы лежат в папке `integrations/` репозитория.

## Фрагмент HTML

Вставьте это перед `</body>`, с адресом вашего сервера и адресом страницы:

```html
<script async
  src="https://monit.example.com/api/public/status/my-page/banner.js"
  data-position="top" data-show="issues" data-lang="en"></script>
```

| Атрибут | Значения | По умолчанию |
|---|---|---|
| `data-position` | `top`, `bottom` | `top` |
| `data-show` | `issues` (только когда что-то не так), `always` | `issues` |
| `data-lang` | `en`, `fr`, `de`, `es`, `it`, `pt`, `pt-BR`, `ru`, `zh-Hans` | язык страницы, иначе `en` |

У скрипта нет зависимостей, он рисует внутри Shadow DOM, так что ваши стили его
не затрагивают, следует светлым или тёмным предпочтениям посетителя и может быть
закрыт (до закрытия вкладки браузера). Он читает публичный JSON страницы, который
сервер разрешает запрашивать любому сайту (`Access-Control-Allow-Origin: *`, без
cookie). Таким способом открывается только публичный документ страницы статуса;
остальной API сохраняет свои правила.

## WordPress

Скопируйте `integrations/wordpress/dumbmonit-status-banner` в
`wp-content/plugins/`, активируйте его, затем откройте **Settings > DumbMonit
Banner** и укажите URL страницы статуса
(`https://monit.example.com/api/public/status/my-page`), положение и режим
показа. Плагин запрашивает JSON на сервере, кэширует его на минуту и
экранирует всё, что выводит. WordPress отклоняет запросы к приватным адресам,
поэтому сервер DumbMonit должен быть доступен по публичному адресу.

## Включение в PHP

Для любого сайта на PHP, без фреймворка:

```php
require __DIR__ . '/banner.php';
dumbmonit_banner('https://monit.example.com/api/public/status/my-page',
    ['position' => 'top', 'show' => 'issues', 'ttl' => 60]);
```

Вспомогательная функция принимает только URL `http` и `https`, использует
таймаут 3 секунды, не следует за перенаправлениями, хранит файловый кэш во
временном каталоге и ничего не выводит, если сервер недоступен. См.
`integrations/php/example.php`.
