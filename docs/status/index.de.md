# Status

Was Sie denen sagen, die von Ihren Diensten abhängen. In der App ist es **Status** im linken Menü (`g s`), mit zwei Tabs.

| Tab | Was er tut | Lesen |
|---|---|---|
| **Seiten** | Öffentliche Statusseiten, die Dienste, die sie zeigen, und die Störungen und Wartungen, die Sie dort ankündigen | [Statusseiten](../using/status-pages.md) |
| **Berichte** | Der Verfügbarkeitsexport (SLA) eines Zeitraums und die geplanten E-Mail-Berichte, mit dem Verlauf ihres Versands (Administratoren) | [Berichte](../using/reports.md) |

Eine Statusseite zeigt nur, was Sie darauf setzen: die Bezeichnung, die Sie jedem Dienst geben, seinen Zustand und seine Verfügbarkeit. Namen, Adressen und Kennungen der Monitore verlassen den Server nie.
