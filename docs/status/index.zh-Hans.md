# 状态

您向依赖您服务的人传达的信息。在应用中是左侧菜单的**状态**(`g s`),有两个标签页。

| 标签页 | 作用 | 阅读 |
|---|---|---|
| **页面** | 公开的状态页、它们所展示的服务,以及您在其上发布的故障和维护公告 | [状态页](../using/status-pages.md) |
| **报告** | 某一时段的可用性(SLA)导出和定时发送的电子邮件报告,以及发送历史(管理员) | [报告](../using/reports.md) |

状态页只显示您放上去的内容:您为每个服务设置的标签、状态和可用率。监控项的名称、地址和标识符绝不会离开服务器。
