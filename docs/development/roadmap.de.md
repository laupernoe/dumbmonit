# Roadmap {#roadmap}

Was ausgeliefert ist, in Arbeit ist und geplant wird, steht auf dem öffentlichen Projektboard:
[DumbMonit Roadmap](https://github.com/users/laupernoe/projects/2). Prioritäten und Zeitplan
können sich ändern; das Board ist ein lebendiger Plan, kein Versprechen.

- **Ausgelieferte Änderungen** stehen im
  [Changelog](https://github.com/laupernoe/dumbmonit/blob/main/CHANGELOG.md) und in den Notizen
  jedes [GitHub-Releases](https://github.com/laupernoe/dumbmonit/releases).
- **Ideen und Fehler** gehören in den
  [Issue-Tracker](https://github.com/laupernoe/dumbmonit/issues). Eröffnen Sie ein Issue,
  bevor Sie Code für etwas Größeres schreiben.
- **Sicherheitskorrekturen** werden in den Release-Notes und als GitHub-Security-Advisories
  mit ihrer CVE- oder GHSA-Kennung angekündigt.

DumbMonit befindet sich in der Alpha-Phase: Rechnen Sie damit, dass sich API und Datenmodell
weiterentwickeln, bis eine stabile Linie angekündigt wird. Zum Mitmachen siehe den
[Contributing-Leitfaden](https://github.com/laupernoe/dumbmonit/blob/main/CONTRIBUTING.md) und
die [Governance](https://github.com/laupernoe/dumbmonit/blob/main/GOVERNANCE.md).
